# Abhi Labs Website Redesign — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild abhilabs.app as a premium, mobile-first, system-adaptive dark/light, Lighthouse 95+ static site using Tailwind CLI.

**Architecture:** Pure static HTML with Tailwind CLI (purged CSS output), CSS custom properties for theming, per-app accent via CSS class on `<html>` element, no JS frameworks.

**Tech Stack:** HTML5, Tailwind CSS v3 (CLI build), CSS custom properties, vanilla JS (mobile menu + IntersectionObserver), Plus Jakarta Sans (Google Fonts), inline SVG icons.

## Global Constraints

- No external CDN CSS/JS at runtime (except Google Fonts preconnect)
- All images: `loading="lazy"` except hero/above-fold → `fetchpriority="high"`
- `prefers-reduced-motion`: all transitions/animations → `duration-0`
- `:focus-visible` keyboard focus rings on all interactive elements
- Semantic HTML: `<header>`, `<nav>`, `<main>`, `<footer>`, `<article>` for app cards
- Privacy policy URLs: `/privacy/[app]/` (NOT Google Sites)
- Hits.sh badge: removed entirely
- Font Awesome: replaced with inline SVG
- Social proof values (star ratings, download counts): **REQUIRES USER INPUT from Play Console**
- `aria-current="page"` on active nav link; hamburger with `aria-expanded`
- Skip-to-content link on every page
- `<link rel="canonical">` + OG tags + JSON-LD on every page

### Mobile menu JS (before `</body>`)
```html
<script>
  const btn = document.querySelector('.nav-hamburger');
  const links = document.querySelector('.nav-links');
  btn.addEventListener('click', () => {
    const open = btn.getAttribute('aria-expanded') === 'true';
    btn.setAttribute('aria-expanded', String(!open));
    links.classList.toggle('nav-links--open');
  });
  // Close on outside click
  document.addEventListener('click', e => {
    if (!e.target.closest('.nav-container')) {
      btn.setAttribute('aria-expanded', 'false');
      links.classList.remove('nav-links--open');
    }
  });
  // Reveal animation
  const io = new IntersectionObserver(entries => {
    entries.forEach(e => { if (e.isIntersecting) { e.target.classList.add('revealed'); io.unobserve(e.target); } });
  }, { threshold: 0.1 });
  document.querySelectorAll('.reveal').forEach(el => io.observe(el));
</script>
```

### Task 12: Lighthouse Audit

**Goal:** Verify Lighthouse 95+ on Performance, Accessibility, Best Practices, SEO for `index.html`.

- [ ] **Step 1: Run local server**

```bash
npx serve . -p 3000
```

- [ ] **Step 2: Run Lighthouse**

Open Chrome DevTools → Lighthouse tab → run on `http://localhost:3000/`. Target scores: Performance ≥95, Accessibility ≥95, Best Practices ≥95, SEO ≥95.

**Common fixes if Performance < 95:**
- LCP image not using `fetchpriority="high"` → add it to first visible screenshot
- Google Fonts blocking render → add `<link rel="preload" as="style">` or switch to `font-display: swap`
- `styles/output.css` not minified → ensure `--minify` flag in build script

**Common fixes if Accessibility < 95:**
- Missing `alt` attributes → add descriptive alt text to all `<img>` tags
- Color contrast failure → check `--text-2` on `--bg-subtle` (target ≥4.5:1)
- Missing form labels → ensure all interactive elements have accessible names

**Common fixes if SEO < 95:**
- Missing meta description → verify each page has `<meta name="description">`
- Missing canonical → verify `<link rel="canonical">` on each page

- [ ] **Step 3: Fix issues and re-run until all scores ≥ 95**

- [ ] **Step 4: Final build**

```bash
npm run build
git add styles/output.css
git commit -m "perf: final Lighthouse-optimized CSS build"
```
